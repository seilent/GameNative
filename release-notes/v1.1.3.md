## What's New

Controller navigation fixes.

### Controller
- Focus selector appears on launch without needing a shoulder press first
- D-pad recovers focus when it gets lost (previously only L1/R1 did)
- Game detail, edit container, and quick menu grab focus correctly when opened by touch
- Quick menu tabs switch with L1/R1
